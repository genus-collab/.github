# GENUS (Geometry, Enumeration, Strings)

An open-source public collaborative workspace for research in topological
strings and enumerative geometry.

**Strands:** [foundations](https://github.com/genus-collab/foundations) ·
[solutions](https://github.com/genus-collab/solutions) ·
[structures](https://github.com/genus-collab/structures) ·
[enhancements](https://github.com/genus-collab/enhancements) ·
shared knowledge: [atlas](https://github.com/genus-collab/atlas) ·
administration: [meta](https://github.com/genus-collab/meta)

## About

- **Who maintains it:** the GENUS Steering Committee and Strand Leads
  (see the [charter](https://github.com/genus-collab/meta/blob/main/CHARTER.md), § Governance).
- **What it is for:** frontier research done collectively and in the open.
  Workshop PDFs are in-progress, often AI-assisted, unrefereed working documents
  credited to the GENUS collaboration; curated human-written surveys go to arXiv.
- **How contributed material is used:** text and PDFs are CC BY 4.0, code MIT,
  data CC0 (provisional). 
- **Contact the SC:** open an issue in [meta](https://github.com/genus-collab/meta/issues).

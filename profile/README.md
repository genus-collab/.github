# Topological String Lab (TS-Lab)

An open-source public collaborative workspace for research in topological
strings and enumerative geometry.

**Strands:** [foundations](https://github.com/topological-strings-lab/foundations) ·
[solutions](https://github.com/topological-strings-lab/solutions) ·
[structures](https://github.com/topological-strings-lab/structures) ·
[enhancements](https://github.com/topological-strings-lab/enhancements) ·
shared knowledge: [atlas](https://github.com/topological-strings-lab/atlas) ·
administration: [meta](https://github.com/topological-strings-lab/meta)

## About

- **Who maintains it:** the TS-Lab Steering Committee and Strand Moderators
  (see the [charter](https://github.com/topological-strings-lab/meta/blob/main/CHARTER.md), § Governance).
- **What it is for:** frontier research done collectively and in the open.
  Workshop PDFs are in-progress, often AI-assisted, unrefereed working documents
  credited to the TS-Lab Collective; curated human-written surveys go to arXiv.
- **How contributed material is used:** text and PDFs are CC BY 4.0, code MIT,
  data CC0 (provisional). Whether repository content may be used to train AI
  models is an open question for the community; until it is settled, no
  content is supplied to third parties for training.
- **Contact the SC:** open an issue in [meta](https://github.com/topological-strings-lab/meta/issues).
